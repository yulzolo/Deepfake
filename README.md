# Deepfake

**Контекст:** Социальной сети нужно оценивать достоверность поста. 

**Цель:** экспериментальная проверка алгоритма генерации дипфейков на основе нейронной сети с архитектурой двойного энкодера и механизмом AdaIN, обеспечивающего перенос черт лица при сохранении позы, мимики и освещения из целевого видео

---

## Задачи

- запуск модели и проверка её работоспособности;
- запуск процесса обучения нейронной сети;
- проверка корректности обучения;
- исследование возможных способов повышения качества модели:
  - аугментация данных;
  - расширение датасета;
  - использование предобученных моделей;
  - исследование альтернатив механизму AdaIN.
